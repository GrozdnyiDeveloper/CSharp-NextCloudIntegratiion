# Интеграция с NextCloud
В данном репозитории представлены примеры консольных приложений используемых для настройки интеграции файловой системы NextCloud с системой Dynamics 365. 

**Архив имеет следующее содержимое:**
- IntegrityAnnotationCheck - Проект, представляет собой консольное приложение, которое производит проход по Примечаниям системы Dynamics 365 с приложенными файлами (параметры поиска задаются в методе GetAnnotationsInfo), производит построение пути до файла в NextCloud и проверяет его наличие. Результаты фиксируются в консоль и логи. 
- IntegrityAnnotationClear - Проект, представляет собой консольное приложение, которое производит проход по Примечаниям системы Dynamics 365 с приложенными файлами (параметры поиска задаются в файле конфигурации), производит построение пути до файла в NextCloud, проверяет его наличие (при отсутствии файла он загружается) и затем очищает его содержимое из Примечания системы Dynamics 365 (для экономии места). Результаты фиксируются в консоль и логи. 
- IntegrityDocumentFix - Проект, представляет собой консольное приложение, которое производит проход по файлам системы NextCloud, созданных за определённый период (параметры поиска задаются в методе FindFiles), загружается его содержимое и проверяет корректность их кодировки. Если файл не соответствует корректной кодировки (Base64), то его содержимое перекодируется и переписывается в NextCloud. Результаты фиксируются в консоль и логи. 
- IntegrityDocumentSort - Проект, представляет собой консольное приложение, которое производит проход по файлам системы NextCloud в соответствии с заданным путём (исходный путь до файлов задаётся в файле конфигурации), проверяет их наличие в записях Примечаний системы Dynamics 365, производим построение пути в NextCloud согласно алгоритму и проверяем его соответствие фактическому расположению файла. При несовпадении путей файл копируется. Результаты фиксируются в консоль и логи.
